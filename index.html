Multi-Class Lung Disease Prediction Using Machine Learning

2026

A machine-learning web application that classifies chest X-ray images into COVID-19, Tuberculosis, Pneumonia, and Normal categories. Images are preprocessed with OpenCV — resized, converted to grayscale — and features extracted using Histogram of Oriented Gradients (HOG). A Support Vector Machine classifier, trained in Scikit-learn, is evaluated on accuracy, precision, recall, F1-score, and confusion matrix, then served through a Flask web application for automated predictions on uploaded images.
